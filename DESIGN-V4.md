# Direction artistique V4 — Basalte & Tuf

## Intention

La V4 évite les deux extrêmes testés précédemment :

- pas de noir/or « luxe template » ;
- pas de bleu acier / interface pseudo-gouvernementale ;
- pas de simple remplacement d'une couleur d'accent.

L'identité repose sur une palette inspirée de matériaux minéraux : **basalte sombre, ivoire chaud, tuf rosé et vert minéral**.

## Palette

- Basalte : `#171514`
- Basalte secondaire : `#1D1A18`
- Ivoire : `#EEE8DF`
- Blanc chaud : `#FAF6EF`
- Tuf : `#A86F63`
- Tuf sombre : `#7D4F47`
- Argile : `#C9977F`
- Vert minéral : `#647269`

## Typographie

- **Manrope** : interface, navigation et titres principaux.
- **Instrument Serif** : mots éditoriaux et accents de marque.

## Principes

Le site public se comporte comme le site d'une entreprise réelle : aucun terme technique lié au serveur, au jeu ou aux scripts n'apparaît dans les contenus destinés aux clients.

La couleur est utilisée pour créer une vraie identité : bande de marque, contrastes chauds, panneaux Logistics, détails de navigation et espaces client. Elle n'est pas utilisée comme un simple surlignage uniforme.

L'espace opérations reste volontairement plus dense et fonctionnel que le site public, tout en reprenant la palette Nairi.

# Nairi Corporation — V5.2 Hybrid

## Principe

Cette version repart **du layout V4**, pas du layout V5.

- mêmes placements que la V4 ;
- mêmes espacements généreux ;
- mêmes tailles de cartes et zones de lecture ;
- même hiérarchie Corporation / Logistics / dossiers ;
- même comportement responsive ;
- mêmes fonctionnalités Supabase et staff.

La V5.2 remplace uniquement l'identité visuelle chaude de la V4 par le langage **Steel & Slate** du thread Nairi.

## Identité conservée du thread

- graphite / noir bleuté ;
- bleu acier `#7A96B8` ;
- bleu clair `#9DB2CC` ;
- Cinzel sur les titres ;
- Plus Jakarta Sans sur les textes ;
- JetBrains Mono uniquement pour les micro-labels ;
- logo métallique désaturé.

## Ce qui n'est volontairement PAS repris de la V5

La V5 comprimait beaucoup plus les sections pour se rapprocher d'une brochure institutionnelle. Cela nuisait à la lecture sur un vrai site et particulièrement dans l'application téléphone.

La V5.2 ne reprend donc pas :

- les sections compactées ;
- les petites cartes carrées très denses ;
- la réduction générale des corps de texte ;
- les gros cadres éditoriaux qui resserraient le contenu ;
- les boutons et zones cliquables réduits.

En résumé : **V4 pour l'ergonomie, Steel & Slate pour l'identité.**

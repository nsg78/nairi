# Post OP Logistics V10

V10 keeps the V9 functionality and makes the public site visually closer to the Post OP Invision/forum identity instead of adding another generic SaaS layer.

## Main changes
- Strong dark-brown Post OP header with postal orange stripe.
- Cream/paper surfaces, brown typography and orange accents.
- More editorial / delivery-network hero and process block.
- Compact, sharper cards and less rounded SaaS styling.
- Partner cards now strictly separate logo area and description area; no image/text overlap.
- Mobile rules tightened for partner logos and public sections.
- V9 request, tracking, partner request, CRM and staff functionality preserved.

No new database migration is required for the visual-only V10 changes. Keep using the V9 SQL already applied.
